## v2.8.1 手动收藏声音—字母块

- 停止根据错题自动写入音标记录；只有用户点击声音—字母块右上角的星标，才会保存该组对应。

- 面板最下方按“同一音标 → 同一字母块”的收藏单词数生成个人排行。
- 新增“音标对应收藏”页面，可以搜索、筛选、播放音标和单词，并查看每组对应包含的全部单词。
- 原来的自动错题历史保留在本机但不再读取或继续累计，不会影响新的手动收藏。

## v2.8.0 按声音拼写

- 错题反馈改为三步训练路径：先听完整发音，再查看“声音块 → 字母块”，最后把字母块按顺序合成完整单词；中文释义不参与拼写路径。
- 每个声音块可以单独播放，并同时显示正确字母块和用户实际写法；例如 `oxygen /ˈɒksɪdʒən/` 会拆为 `/ɒ/→o · /ks/→x · /ɪ/→y · /dʒ/→g · /ən/→en`。
- 扩充分音—拼写映射，插件内 4,148 个词的已知规则分块覆盖率由 94.8% 提升到 96.8%。
- 不规则拼写、弱读、省音和缺失音标不会伪装成普遍规则，而会标成“本词估算”“需整体记忆”“不单独发音”或“音标缺失”。
- 后台会把每次错写按音标聚合并保存在 `chrome.storage.local`；面板最下方显示每个易错音标的累计次数、具体“应写 → 写成”次数和出现过的单词，同一次答题不会因页面重绘重复累计。
- 新增整库自动测试，确保每个词的全部字母和可用音素都不会在分块过程中丢失。

## v2.7.2 雅思口语模板化提取

- 结果会标注适用 Part、口语话题和在答案中的使用位置；例句必须替换好槽位，能够直接朗读。
- 明确排除专有名词、文章专属事实、文学化表达、过度书面语和孤立单词。

## v2.7.0 精听口语素材

## 纠错与手动音标收藏

错拼时，扩展以正确答案的音标为基准，将正确词拆成“声音块 → 正确拼写块”，再对齐用户输入。例如 `waddng → wedding /ˈwedɪŋ/`：

| 声音 | 正确拼写 | 用户写法 | 结论 |
| --- | --- | --- | --- |
| `/w/` | `w` | `w` | 正确 |
| `/e/` | `e` | `a` | 把 `/e/` 应写的 `e` 写成了 `a` |
| `/d/` | `dd` | `dd` | 正确 |
| `/ɪŋ/` | `ing` | `ng` | 漏写 `i` |

绿色表示正确对应，红色表示错误字母，黄色表示漏写部分。每个声音块可以点击播放；带声音的字母块右上角有一个小星星。只有用户主动点击星标时，扩展才会把“音标 + 正确字母块 + 当前单词”保存到 `chrome.storage.local`。面板底部按同一组音标对应收藏的单词数生成排行，“音标对应收藏”页面可以查看和取消具体单词。

## DeepSeek 设置

1. 点击浏览器工具栏中的扩展图标。
2. 在“DeepSeek 词汇应用”中输入 API Key。
3. 点击“保存到本机”。密码框不会回显已经保存的 Key。
4. 需要停用时关闭开关；点击“清除 Key”会同时清除本地解释缓存。

API Key 不写入扩展源码或发布 ZIP，只保存在当前浏览器的本地扩展存储中。普通单词解释只发送当前英文单词和本地中文释义；精听口语素材仅在用户主动点击后发送当前页提取的正文/字幕（最多 60,000 个字符）。两种功能都不会发送用户输入的拼写或错误映射。返回的单词解释按词缓存 30 天，精听收藏和最近一次结果保存在本机。

## 候选词规则

- 本地词库共 4148 条：答案词 1746 条、雅思听力核心词 1950 条，以及 10 类场景词的成员关系。
- 近音与形近两个通道独立筛选、合并去重，最多显示 5 个；符合几个就显示几个，当前词始终排除。
- 短词近音要求音节相同、音素编辑距离不超过 3，替换音属于预设易混音对；形近词同时检查音素和 Damerau–Levenshtein 字母距离。
- 7 个字母以上的中长词适当放宽，尤其是音近：允许音节数相差 1；10 字母词音素距离上限可到 5；前 5 个音素或较长共同前缀相同也可纳入。
- 重点词只在同等条件下提高排序，不绕过相似度门槛。

## 发音

- `·` 播放主词，数字 `1`–`5` 播放相似词。
- 英式完整词音频优先使用网站音频，美式及必要回退使用在线发音。
- 短音素示范音随扩展离线打包，来自 `zhen-ke/phonetic-Symbols` 的 KK 音频。

2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。

## 个人使用与更新

本项目可以保存在私人 GitHub 仓库中，并在 Chrome 中以“加载已解压的扩展程序”方式使用。

首次安装：

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。

以后更新：

1. 双击项目文件夹中的 `更新插件.command`。
2. 等待它从私人 GitHub 仓库拉取最新版本。
3. 在扩展管理页找到“听写辨音助手”，点击“重新加载”。

开发者模式加载的本地扩展不会像 Chrome Web Store 扩展一样在后台自动更新；上述方式会保护尚未提交的本地修改，并在更新完成后打开扩展管理页。

### 用户数据不会随更新消失

读音对比收藏列表、音标对应收藏、精听词组收藏、最近一次精听分析、DeepSeek API Key、旧版错音历史、面板位置和解释缓存都保存在 Chrome 的扩展本地存储中，不保存在项目源码或 GitHub 仓库中。使用 `更新插件.command` 在原文件夹拉取代码，然后在扩展管理页点击“重新加载”，不会清空这些数据。

为保持用户数据，请遵守以下规则：

- 始终使用当前项目文件夹更新，不要复制到新路径后重新加载。
- 更新时只点击“重新加载”，不要先删除扩展再重新安装。
- 不要在 Chrome 设置中清除该扩展的站点/扩展数据。
- “清除 Key”只用于用户确实希望删除 API Key 的情况；普通更新不需要重新填写 Key。

源码更新流程不得调用 `chrome.storage.local.clear()`，也不得用空收藏列表或空 API Key 覆盖已有值。新增数据结构时应采用兼容迁移，保留 `pronunciationComparisonsV1`、`soundSpellingFavoritesV1`、`speakingMaterialFavoritesV1` 和 `deepseekApiKey`。
