## 判题与隐私保护

- 拼写阶段不在页面上显示当前词、中文释义、音标、发音按钮或相关词。
- 网站判定正确或错误后才显示新结果。进入下一词后，可以保留上一词面板；候选中若包含当前正在拼写的词，会立即排除。
- 面板常驻、可拖动、可拉伸、可关闭。扩展弹窗中的“重新显示已关闭的面板”可以恢复。
- 爱听写支持智能模式四个选项、隐藏选项后的“认识 / 不认识”，以及答案词拼写模式。

## 纠错与个人映射记录

错拼时，扩展以正确答案的音标为基准，将正确词拆成“声音块 → 正确拼写块”，再对齐用户输入。例如 `waddng → wedding /ˈwedɪŋ/`：

| 声音 | 正确拼写 | 用户写法 | 结论 |
| --- | --- | --- | --- |
| `/w/` | `w` | `w` | 正确 |
| `/e/` | `e` | `a` | 把 `/e/` 应写的 `e` 写成了 `a` |
| `/d/` | `dd` | `dd` | 正确 |
| `/ɪŋ/` | `ing` | `ng` | 漏写 `i` |

绿色表示正确对应，红色表示错误字母，黄色表示漏写部分。每个声音块可以点击播放。个人记录按“声音 + 正确拼写 + 错误写法”累计，保存在 `chrome.storage.local`，同一次作答不会因重绘重复计数。

## DeepSeek 设置

1. 点击浏览器工具栏中的扩展图标。
2. 在“DeepSeek 词汇应用”中输入 API Key。
3. 点击“保存到本机”。密码框不会回显已经保存的 Key。
4. 需要停用时关闭开关；点击“清除 Key”会同时清除本地解释缓存。

API Key 不写入扩展源码或发布 ZIP，只保存在当前浏览器的本地扩展存储中。启用后，扩展只向 DeepSeek 发送当前英文单词和本地中文释义，不发送用户输入的拼写、错误映射或其他作答记录。返回内容按单词缓存 30 天，最多保存 120 个词。

## 候选词规则

- 本地词库共 4148 条：答案词 1746 条、雅思听力核心词 1950 条，以及 10 类场景词的成员关系。
- 近音与形近两个通道独立筛选、合并去重，最多显示 5 个；符合几个就显示几个，当前词始终排除。
- 短词近音要求音节相同、音素编辑距离不超过 3，替换音属于预设易混音对；形近词同时检查音素和 Damerau–Levenshtein 字母距离。
- 7 个字母以上的中长词适当放宽，尤其是音近：允许音节数相差 1；10 字母词音素距离上限可到 5；前 5 个音素或较长共同前缀相同也可纳入。
- 重点词只在同等条件下提高排序，不绕过相似度门槛。

## 发音

- `·` 播放主词，数字 `1`–`5` 播放相似词。
- 英式完整词音频优先使用网站音频，美式及必要回退使用在线发音。
- 短音素示范音随扩展离线打包，来自 `zhen-ke/phonetic-Symbols` 的 KK 音频。

## 安装

1. 解压发布 ZIP。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `ielts-soundalike-helper` 文件夹。
6. 刷新听写页面；爱听写请进入 `/home` 学习页。

如果浏览器中仍有旧版，请先删除旧版或确保只启用一个版本。

第三方服务及数据来源见 `THIRD_PARTY_NOTICES.md`。

## 个人使用与更新

本项目可以保存在私人 GitHub 仓库中，并在 Chrome 中以“加载已解压的扩展程序”方式使用。

首次安装：

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。

以后更新：

1. 双击项目文件夹中的 `更新插件.command`。
2. 等待它从私人 GitHub 仓库拉取最新版本。
3. 在扩展管理页找到“听写辨音助手”，点击“重新加载”。

开发者模式加载的本地扩展不会像 Chrome Web Store 扩展一样在后台自动更新；上述方式会保护尚未提交的本地修改，并在更新完成后打开扩展管理页。
